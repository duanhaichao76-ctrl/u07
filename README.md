# u07

白色简约风格的安卓日语五十音学习应用，支持 Android 9 及以上。

## 下载

在 Releases 页面下载 `u07-0.1.1-dev.apk`。本版本为已签名的开发测试版，尚未完成真实手机安装验证。

## 功能

- 平假名、片假名切换，清音、浊音、半浊音与拗音，共 104 个学习条目。
- 使用设备日语合成语音；离线发音需要设备预先安装可离线工作的日语语音包。
- 听音选择、罗马音选择、平片假名匹配；自定义 1–104 题、错题复习。
- 手动标记学会、本地进度与测试记录。
- KanjiVG 笔顺动画、字形描红、自由手写。组合拗音目前提供字形描红，笔顺需按单字练习。

## 构建与验证

详见 `VERIFICATION.md`。标准 Gradle 工程与不依赖 Gradle 插件的官方 SDK 构建脚本 `scripts/build_sdk.py` 均已提供。发布安装包的 SHA-256 校验值见 `downloads/SHA256SUMS.txt`。

无账号、无广告、不请求网络权限。卸载通常会清除本地进度。本版本采用开发签名，正式发布前应使用长期保存的正式签名密钥，并完成设备测试。
